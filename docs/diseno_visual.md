# Diseño visual de Ruta Facil El Alto

## Identidad

La app usa una mascota tipo condor caricatura para comunicar cercania,
movilidad y pertenencia local. La marca combina:

- Condor como mascota.
- Pin de ubicacion.
- Ruta curva tipo mapa.
- Iconos de minibus, trufi y micro.
- Nombre `Ruta Facil`.

## Paleta

- Naranja: identidad principal y tema predeterminado.
- Azul: minibuses y rutas principales.
- Verde: trufis.
- Amarillo/naranja: micros.
- Rojo: cambios por feria, bloqueo, marcha o ruta modificada.
- Azul oscuro: tema nocturno.

## Experiencia

- El usuario puede elegir tema naranja o tema oscuro.
- El blanco puro se evita para reducir brillo y dar una apariencia mas calida.
- Las pantallas usan tarjetas con bordes suaves de 8 px.
- Los estados vacios usan la mascota para guiar al usuario sin verse como error.
- El mapa muestra leyenda para recorrido, paradas y buses activos.
